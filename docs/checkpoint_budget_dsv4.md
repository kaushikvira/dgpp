## KV cache cost

- A latent row (window and compressed entries alike): 583 bytes — `head_dim - rope_head_dim` e4m3 values with one e8m0 per 64, plus the 64 rope dims kept bf16 (`model.py: act_quant(kv[..., :-rd], 64, ...)`); stored in a 584-byte record.
- An index-key row: 68 bytes — 128 dims after the Hadamard rotation, e2m1 with an e8m0 per 32 (`fp4_act_quant(kv, 32, True)`).
- Global (paged) cache: **3509 bytes per context token per rank** — every compressed layer keeps its OWN cache (21 layers at ratio 4 = 163 B/token each, 20 layers at ratio 128 = 4.6 B/token each).
- Per request slot: 3.06 MiB of 128-row window rings (43 layers x 128 rows) plus the compressor tail state (21 x 2 x 8 x 512 fp32 = 672 KiB at ratio 4, 10.0 MiB at ratio 128).
- At 1,048,576 positions: 3.43 GiB per rank (128 KiB of positions: 438.62 MiB).
